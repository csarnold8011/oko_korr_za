# Ökonometria korrepetálás

Jelszóval védett felkészítő anyagok (tananyag, képlettár, két munkalap) a BME Ökonometria 1. dolgozatához.

A `data/` mappában az oldalak titkosítva vannak (AES-256-GCM). A belépést és a kulcs kiadását egy Google Apps Script végzi, amelynek címe a `config.js` fájlban van.
